# Student Performance Data Analysis

## Project Overview
This project analyzes student academic performance using Python. It explores Mathematics, Reading, and Writing scores to understand students' academic results.

## Objectives
- Load and explore student data from a CSV file.
- Calculate average marks for each student.
- Assign grades based on average scores.
- Identify missing values.
- Create charts to visualize academic performance.
- Generate useful performance insights.

## Tools and Technologies
- Python
- NumPy
- Pandas
- Matplotlib
- Google Colab

## Project Workflow
1. Dataset collection and loading.
2. Data exploration.
3. Average score calculation.
4. Grade assignment.
5. Missing value identification.
6. Data visualization.
7. Performance analysis and conclusions.

## Visualizations
The project includes:
- Average Marks by Subject
- Student Grade Distribution
- Mathematics Score Distribution
- Mathematics vs Reading Performance

## Dataset
Students Performance in Exams dataset from Kaggle.

## Conclusion
This project demonstrates how Python libraries can be used to analyze educational data, identify academic performance patterns, and present findings through visualizations.
